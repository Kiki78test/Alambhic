Services externes

Pilotage du projet
Mis à jour le 23 novembre 2026

Alamb’hic tourne sur GitHub, Render (service web et base), la connexion Google, les services de notification des navigateurs et, une fois la clé renseignée, Resend pour les e-mails. L'assistant IA de l'aide est facultatif.

En service

GitHubDépôt privé Kiki78test/Alambhic : code source et documentation.GratuitCode uniquementAccès de l'appli Claude autorisé sur le dépôt.
Render — service webHéberge le serveur Node (site, API, temps réel, pages légales). Redéploie à chaque envoi sur main.Offre Starter, ~7 $/mois (toujours éveillé)Transit des données des joueursRégion Francfort. Blueprint render.yaml. Variables : SESSION_SECRET (générée), DATABASE_URL (reliée), GOOGLE_CLIENT_ID, ADMIN_EMAILS, CONTACT_EMAIL, MONITOR_KEY, MONITOR_ORIGIN, RESEND_API_KEY, MAIL_FROM, BASE_URL, ANTHROPIC_API_KEY (facultatif).

Google IdentityBouton « Continuer avec Google ».GratuitE-mail, prénom, identifiant GoogleProjet Google Cloud « YouDrink », client OAuth « Application Web », origine autorisée https://alambhic.onrender.com (ajouter le futur domaine). Variable GOOGLE_CLIENT_ID.
Web Push (navigateurs)Notifications appli fermée : le serveur chiffre chaque notification et la remet au service du navigateur (Google pour Chrome et Android, Apple, Mozilla, Microsoft).GratuitAdresse d'abonnement de l'appareil, texte chiffré des notificationsClés VAPID créées automatiquement et gardées en base (table settings) ; ou variables VAPID_PUBLIC_KEY / VAPID_PRIVATE_KEY. Rien à faire sur Render.
ResendE-mails : lien de nouveau mot de passe.Gratuit jusqu'à 3 000 e-mails/moisAdresse e-mail du joueurMême équipe Resend qu'Airmony et Hermaion. Variables RESEND_API_KEY, MAIL_FROM (expéditeur sur un domaine vérifié dans Resend), BASE_URL. À renseigner : sans clé, le mot de passe oublié affiche « envoi pas encore activé ».
GitHub ActionsContrôle de sécurité des dépendances chaque lundi ; fabrication de l'APK de test.Gratuit (minutes incluses)Code uniquementFichiers .github/workflows/securite.yml et android.yml. APK dans Releases → « Appli Android (test) ».
Anthropic (facultatif)Assistant de l'aide : reformule une réponse à partir des questions fréquentes.Au message (quelques centimes par jour au plus)Texte de la question, sans identitéVariable ANTHROPIC_API_KEY (et ANTHROPIC_MODEL, par défaut claude-sonnet-5-5). Sans clé, l'aide fonctionne avec les réponses toutes prêtes.
